# 🍭 귀여운 음식 잡기 게임 (Cute Food Catching Game)

가볍고 귀여운 파이게임 프로젝트입니다! 사과와 계란은 통과시키고, 치킨과 라면은 클릭해서 잡아보세요.

## 시작하기
1.  Python 3.x 가 설치되어 있어야 합니다.
2.  `pygame` 라이브러리를 설치합니다:
    ```bash
    pip install pygame
    ```
3.  게임을 실행합니다:
    ```bash
    python main.py
    ```

## 게임 방법
*   **사과, 계란**: 입으로 들어가게 통과시킵니다.
*   **치킨, 라면**: 마우스로 클릭해서 잡습니다!
*   **목표**: 30초 동안 최대한 많은 치킨과 라면을 잡으세요.

## 배포
이 프로젝트는 `pygbag`을 사용하여 웹에서 실행 가능하도록 구성되었습니다.
